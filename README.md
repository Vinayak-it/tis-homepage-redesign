# Tulas International School — Homepage Redesign

A modern, responsive redesign of the Tulas International School (TIS) homepage, created as part of the TIS Homepage Redesign assignment.

The project focuses on creating a premium school website experience with strong visual hierarchy, responsive layouts, smooth animations, interactive sections, and a clear admissions journey.

## Project Overview

The redesigned TIS homepage presents the school's academic environment, boarding life, sports, achievements, parent experiences, campus spaces, and admissions information through a modern single-page experience.

The design follows a minimal editorial visual style while retaining the school's identity and important information.

---

## Features

- Responsive single-page homepage
- Premium editorial-style visual design
- Animated hero section
- Smooth scroll navigation
- Dark / Light theme switcher
- Responsive mobile navigation
- Animated section reveals using Framer Motion
- Interactive sports carousel
- Interactive achievements/year selector
- Automatic parent testimonial carousel
- Interactive campus / virtual tour section
- Responsive layouts for desktop, tablet, and mobile

- Semantic HTML structure

---

## Standout Features

### 1. Animated Theme Switcher

Users can switch between dark and light visual themes using the theme toggle in the navigation bar.

### 2. Interactive Sports Carousel

The Beyond Academics section presents TIS sports through an interactive carousel with navigation controls.

### 3. Interactive Achievements Timeline

Users can select different achievement years to explore corresponding milestones and achievements.

### 4. Interactive Campus Experience

The Virtual Tour section allows users to explore different campus locations, including:

- Entrance
- Academics
- Library
- Sports
- Boarding
- Campus

### 5. Animated Testimonials

Parent testimonials automatically transition between different experiences using an animated carousel.

Installation
Clone the repository:
git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project directory:
cd tis-homepage-redesign

Install dependencies:
npm install

Start the development server:
npm run dev

The application will be available on the local development server provided by Vite.
Production Build

To create a production build:
npm run build

The project has been tested successfully using the production build command.
Responsive Testing
The website was tested across:
- Desktop — 1280px+
- Tablet — approximately 768px
- Mobile — approximately 375px

The layout, navigation, cards, carousels, typography, and spacing were checked across different viewport sizes.

Design Approach
The redesign uses:
- Large editorial typography
- High-quality TIS photography
- Minimal layouts
- Strong visual hierarchy
- Subtle motion
- Interactive components
- Responsive spacing
- Dark and light visual themes

The goal is to create a polished and premium school website experience while keeping the content easy to navigate.

Performance & Code Quality
- Production build verified using npm run build

- Images use descriptive alt attributes
